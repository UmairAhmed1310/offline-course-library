# Bits, Bytes and Colour (sample course)

A short sample used to check the importer (about 2 hours).

## Module 1 · Bits and bytes

**link:** D1

A **bit** is one binary digit. A **byte** is eight bits. `1 byte = 8 bits`, so a
4-byte word holds 32 bits.

| Unit | Bits |
| --- | --- |
| bit | 1 |
| byte | 8 |
| kilobyte | 8000 (decimal) |

### Recall check

How many bits are in a byte? (1) Eight. (2) Four. (3) Sixteen.

### Remember

A byte is eight bits; a nibble is four.

## Module 2 · Colour models

**link:** D2

RGB is additive and used by screens. CMYK is subtractive and used by print.
Hex colour codes are RGB written in base 16.

### Recall check

Which model do printers use? (1) CMYK. (2) RGB.

### Remember

CMYK for print, RGB for screens.

### 0.6 Diagnostic

Answer before Module 1.

**D1.** How many bits are in a byte? A. 4 · B. 8 · C. 16 · D. 32

**D2.** Which model is additive? A. RGB · B. CMYK · C. Pantone · D. RAL

**D3.** What does a hex colour code encode? A. RGB values · B. Print ink · C. File size · D. Screen brightness

## Practice Lab

**Q1.** How many bits are in a byte? (mcq) A. 4 · B. 8 · C. 16 · D. 32

**Q2.** Which two statements about RGB are true? (select two) A. It is additive. B. It is used by screens. C. It is used by printers. D. It is subtractive.

**Q3.** A word is 4 bytes. How many bits is that? (numeric) Enter a whole number.

**Q4.** Explain in one sentence why a print shop does not use RGB. (short answer) Write your answer.

**Q5.** Which colour model is subtractive? (mcq) A. RGB · B. CMYK · C. HSL · D. Hex
